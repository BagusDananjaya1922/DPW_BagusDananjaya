Penjelasan AJAX dan jQuery

1. Pengertian AJAX

AJAX (Asynchronous JavaScript and XML) merupakan teknik dalam pengembangan website yang memungkinkan proses pengambilan atau pengiriman data ke server dilakukan tanpa harus me-refresh halaman secara keseluruhan. Dengan cara ini, tampilan web bisa diperbarui secara langsung di bagian tertentu saja.

2. Pengertian jQuery

jQuery adalah library JavaScript yang dibuat untuk mempermudah penulisan kode. Dengan jQuery, kita bisa lebih mudah dalam mengatur elemen HTML, menangani event, membuat animasi, serta menjalankan AJAX dengan lebih sederhana.

3. Cara Menggunakan jQuery

Untuk menggunakan jQuery, cukup menambahkan script jQuery ke dalam halaman HTML. Biasanya menggunakan CDN seperti berikut:

<script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
